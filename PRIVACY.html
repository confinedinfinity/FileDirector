日本語

本アプリが扱う情報

本アプリは、利用者のパソコン上で動作するデスクトップアプリケーションです。 メディアファイル（画像・動画・音声）とその情報を、利用者のパソコンと、 その利用者が指定した保存先のみで扱います。

開発者への送信

本アプリは、開発者に対していかなる情報も送信しません。 利用状況の収集、解析、広告のいずれも行いません。

Google Drive へのアクセス

利用者が Google アカウントを接続した場合に限り、本アプリは Google Drive を バックアップの保存先として使用します。

  • 使用目的は、利用者が選んだファイルの保存と、その確認のみです
  • 接続は利用者自身の操作（Google の画面での「許可」）によってのみ行われます
  • 認証情報（トークン）は利用者のパソコン内（rclone の設定ファイル）に保存され、 開発者はこれを受け取りません
  • 接続は Google アカウントの設定からいつでも取り消せます

第三者への提供

本アプリが利用者の情報を第三者へ提供することはありません。 保存先（ローカルフォルダ、Google Drive 等）は利用者自身が設定したものであり、 その保存先の取り扱いは各サービスの規約に従います。

外部ツール

本アプリは FFmpeg、yt-dlp、gallery-dl、Python などの外部ツールを 利用者のパソコン上で利用します。これらの動作は各ツールの規約に従います。

English

What this application handles

FileDirector is a desktop application that runs on the user's own computer. It handles media files (images, video, audio) and their metadata only on the user's computer and on destinations the user configures.

No transmission to the developer

This application sends no information to the developer. There is no telemetry, analytics, or advertising.

Google Drive access

Only when the user connects a Google account, this application uses Google Drive as a backup destination.

  • It is used solely to store files the user has selected, and to verify them
  • The connection is made only by the user's own action (pressing "Allow" on Google's screen)
  • Credentials (tokens) are stored on the user's computer (in rclone's configuration file); the developer does not receive them
  • Access can be revoked at any time from the user's Google Account settings

No sharing with third parties

This application does not provide user information to third parties. Destinations (local folders, Google Drive, etc.) are configured by the user, and their handling follows the terms of those respective services.

External tools

This application uses external tools such as FFmpeg, yt-dlp, gallery-dl and Python on the user's own computer. Their behavior follows their own terms.
